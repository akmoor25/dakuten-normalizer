# Change Log

All notable changes to the "dakuten-normalizer" extension will be documented in this file.

## [1.0.0] - 2026-08-29

### Added
- Initial release.
- Detect combining characters (U+3099, U+309A).
- Highlight combinations in the editor.
- Show warnings in the Problems panel.
- Provide Quick Fix actions to normalize characters to NFC format.
- Add `dakuten-normalizer.normalizeAll` command for bulk normalization.
